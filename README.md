# OpenPerfAgent blog

Static website for the who-ate-my-flops performance optimization write-up.

The site has no build step. To preview locally:

```sh
python3 -m http.server 8103
```

Open http://localhost:8103/who-ate-my-flops/. Publish the repository root with GitHub Pages when ready.

The article and its assets live in `who-ate-my-flops/`, for
https://openperfagent.github.io/who-ate-my-flops/.
The root page redirects there until an organization homepage is ready.
